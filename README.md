# GaN-on-Diamond Lab

Research and development of GaN-on-diamond thermal integration technologies.

---

## Overview

This repository focuses on thermal management solutions for high-power GaN devices using diamond materials.

The objective is to reduce thermal resistance, improve heat extraction capability, and enable next-generation RF, AI, EV, and power electronic systems.

---

## Main Topics

### GaN Thermal Management
- High heat flux cooling
- Thermal bottleneck analysis
- Junction temperature reduction
- Thermal spreading

### Diamond Integration
- Diamond bonding
- Low thermal resistance interfaces
- Direct diamond deposition
- Heterogeneous integration

### Device Applications
- RF amplifiers
- OBC systems
- AI power delivery
- High-frequency electronics
- Optical communication

### Packaging
- Submount design
- Thermal interface materials
- Advanced package cooling
- Flip-chip thermal architecture
